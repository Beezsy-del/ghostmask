GhostMask Architectural Design Principles

Published by GhostMask Documentation Team · Release 1.0 Architecture Notes

Local Boundary Enforcement

The privacy boundary coordinates local observation with model visibility. By decoupling observation from remote transmission, client agents operate without exposing raw browser DOM elements.

Fail-Closed Processing

When an unhandled exception or parsing failure occurs, the outgoing pipeline blocks transmission. No fallback to unredacted content is permitted.
